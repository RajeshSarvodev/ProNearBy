# ProNearBy 🚀

ProNearBy is a location-based service marketplace that connects users with nearby professionals such as plumbers, electricians, carpenters, drivers, and IT support.

## Features
- User registration & login
- Post jobs (login required)
- Register as a professional (login required)
- Location-based matching (city & radius logic)
- Admin dashboard
- View & manage user messages
- Firebase Authentication & Firestore

## Tech Stack
- React (Vite / CRA)
- Firebase Authentication
- Firebase Firestore
- React Router
